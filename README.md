# Emberforge – Ressourcenpaket

Optionales Ressourcenpaket für das Schmiede-Plugin Emberforge auf unserem Minecraft-Server (Paper 26.3).
Der Server bietet es beim Einloggen automatisch an. Ohne Paket funktioniert alles, die Items sehen dann nur wie
Vanilla aus.

- `emberforge-pack.zip`: das Paket (Hammer, Werkzeugteile, glühende Barren, Pfeilspitzen, Qualitäts-Stern).
- Credits und Lizenzen stehen in der ZIP-Datei (`CREDITS.txt`, `LICENSE-TinkersConstruct.txt`). Teile der Texturen
  stammen aus Tinkers' Construct von SlimeKnights (MIT-Lizenz), umgefärbt und kombiniert.
